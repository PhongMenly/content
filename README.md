# 🤖 Content Creation Template — Phong Menly AI System

Đây là hệ thống "bộ não AI" cho việc sản xuất nội dung và xây dựng thương hiệu cá nhân.

## Cách sử dụng nhanh

1. **Mở folder này trong Claude Code** → AI tự động đọc `CLAUDE.md`
2. **Yêu cầu tạo nội dung** → AI áp dụng đúng giọng văn, đúng cấu trúc
3. **Tham khảo context files** khi cần context sâu hơn

---

## Cấu trúc thư mục

```
Content-Creation-Template/
│
├── CLAUDE.md                    ← BỘ NÃO CHÍNH — đọc trước tiên
│
├── context/                     ← Context chi tiết cho AI
│   ├── profile.md               ← Hồ sơ cá nhân Phong Menly
│   ├── icp.md                   ← Chân dung khách hàng mục tiêu
│   ├── business.md              ← Hệ sinh thái kinh doanh & sản phẩm
│   ├── strategy.md              ← Chiến lược nội dung & phát triển
│   ├── metrics.md               ← KPIs & mục tiêu đo lường
│   ├── voice-analysis.md        ← Phân tích giọng văn chi tiết + checklist
│   ├── data/
│   │   └── brand-colors.md      ← Bảng màu thương hiệu (HEX codes)
│   └── images/                  ← Ảnh thương hiệu, logo, reference
│
├── posts/                       ← Bài viết đã hoàn thiện (lưu trữ)
│
├── plans/                       ← Kế hoạch nội dung theo tuần/tháng
│   └── content-plan-template.md ← Template lịch nội dung
│
├── reference/                   ← Tài liệu tham khảo
│   ├── prompt-library.md        ← Bộ prompt mẫu sẵn dùng
│   └── tools-affiliate.md       ← Danh sách tool & affiliate links
│
├── outputs/                     ← Output của AI (bản nháp, scripts)
│
└── scripts/                     ← Scripts tự động hóa (nếu có)
```

---

## Lệnh hay dùng với AI

| Yêu cầu | Mô tả |
|---------|-------|
| `Viết bài Facebook về [chủ đề]` | AI tạo bài theo 4 bước SOP |
| `Viết kịch bản TikTok về [chủ đề]` | Script 30–60 giây, hook mạnh |
| `Repurpose bài này sang TikTok` | Chuyển đổi format |
| `Tạo 3 hook cho chủ đề [X]` | Chỉ viết câu mở đầu |
| `Viết CTA cho bài [X]` | Engagement + Conversion CTA |
| `Lên kế hoạch nội dung tuần này` | Weekly content plan |
