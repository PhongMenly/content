# 📚 Prompt Library — Bộ Prompt Mẫu

> Các prompt đã được kiểm tra thực tế, dùng trực tiếp vào Claude / ChatGPT.

---

## Prompt viết bài Facebook

```
Viết 1 bài Facebook theo phong cách Phong Menly về chủ đề: [CHỦ ĐỀ]

Yêu cầu:
- Hook câu đầu gây sốc hoặc bất ngờ, có số cụ thể
- Kể câu chuyện thực tế (1 đoạn ngắn)
- Đưa ra bài học / framework rõ ràng (3-5 điểm)
- Kết bằng câu hỏi mở kích thích bình luận
- Giọng: thân thiện, thực chiến, không giảng đạo
- Không dùng: "trong thời đại công nghệ số", "chìa khóa vàng"
- Độ dài: 200-400 từ, nhiều đoạn ngắn, dễ đọc trên mobile
```

## Prompt viết kịch bản TikTok

```
Viết kịch bản TikTok 45 giây về: [CHỦ ĐỀ]

Cấu trúc bắt buộc:
[0-3s] HOOK: Câu gây sốc / câu hỏi khiến người ta dừng lại
[3-10s] PAIN: Đánh vào nỗi đau / vấn đề người xem đang gặp
[10-35s] SOLUTION: Hướng dẫn 3 bước cụ thể, đơn giản
[35-40s] PROOF: Kết quả / ví dụ thực tế
[40-45s] CTA: Kêu gọi follow / comment / click link

Giọng: nhanh, dứt khoát, như đang nói chuyện với bạn bè
```

## Prompt tạo Hook variations

```
Cho chủ đề: [CHỦ ĐỀ]
Viết 5 câu hook khác nhau theo 5 kiểu:
1. Hook con số: Bắt đầu bằng số cụ thể
2. Hook thất bại: Thừa nhận sai lầm / thất bại
3. Hook câu hỏi: Câu hỏi khiến người đọc tự hỏi bản thân
4. Hook counterintuitive: Đi ngược lại suy nghĩ thông thường
5. Hook kết quả: Bắt đầu từ kết quả phi thường

Áp dụng phong cách Phong Menly: ngắn, trực tiếp, có số liệu thật.
```

## Prompt viết CTA

```
Viết 2 CTA cho bài về [CHỦ ĐỀ]:

CTA 1 (Engagement): Khiến người đọc bình luận — hỏi về kinh nghiệm của họ, không nói "thả tim nhé"
CTA 2 (Conversion): Dẫn về [SẢN PHẨM/AFFILIATE LINK] một cách tự nhiên, không ép buộc

Tone: thân thiện, không spam, cảm giác như lời khuyên chân thành.
```

## Prompt repurpose nội dung

```
Tôi có bài Facebook này: [DÁN BÀI VÀO ĐÂY]

Hãy repurpose thành:
1. Kịch bản TikTok 30s (chỉ lấy 1 insight mạnh nhất)
2. Thread Twitter/X (3-5 tweet)
3. Caption YouTube Short

Giữ nguyên giọng văn Phong Menly, không thêm nội dung mới.
```
